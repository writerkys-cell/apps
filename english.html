목소리 고르기

한 줄씩 들어보고 마음에 드는 것을 고르세요. 이 기기에 설치된 목소리만 나옵니다.

쓸 만한 목소리가 없을 때

맥에서 — 시스템 설정 → 손쉬운 사용 → 말하기 → 시스템 음성 옆 사용자화를 열고, 영어(미국)에서 Ava·Allison·Tom의 향상됨 또는 프리미엄 버전을 내려받으세요. 용량이 크지만 압축 음성과는 소리가 완전히 다릅니다. 내려받은 뒤 크롬을 껐다 켜야 목록에 나타납니다.

아이폰·아이패드에서 — 설정 → 손쉬운 사용 → 음성 콘텐츠 → 음성 → English에서 같은 방식으로 내려받습니다.

크롬보다 사파리에서 이 파일을 열면 애플 목소리가 더 잘 잡히는 경우가 많습니다. 이름에 Google이 붙은 것은 인터넷이 연결돼 있어야 소리가 납니다.
