      기기

      기기 이름은 어느 쪽에서 고쳤는지 표시하는 데만 씁니다.

      적어둔 이름 그대로 버튼이 됩니다. 비워두면 그 버튼은 나오지 않습니다.

      훑기에서 밀린 횟수입니다. 자꾸 지는 항목은 게으름이 아니라 잘못 적힌 항목일 때가 많습니다. 숫자가 신경 쓰이면 꺼두세요.

      동기화

      Supabase 프로젝트의 주소와 anon 키를 넣으면 맥북과 아이폰이 같은 목록을 봅니다. 한쪽에서 고치면 다른 쪽에 바로 옵니다.

      새로 설정한 기기가 빈 목록으로 서버를 덮어쓰지 않도록 막아둡니다. 목록이 크게 줄어드는 변경을 올릴 때는 직전 상태를 서버에 한 벌 남기니, 사고가 나면 되돌리기로 살릴 수 있습니다.

      표 만들기

      Supabase의 SQL Editor에 한 번만 붙여넣고 실행하면 됩니다.

      create table if not exists bangjeom (
  id text primary key,
  data jsonb not null,
  device text,
  updated_at timestamptz not null default now()
);

alter table bangjeom enable row level security;

create policy "anon read"  on bangjeom for select using (true);
create policy "anon write" on bangjeom for insert with check (true);
create policy "anon edit"  on bangjeom for update using (true) with check (true);

alter publication supabase_realtime add table bangjeom;

      백업

      목록 전체를 JSON으로 내려받거나 되돌립니다.

      규칙

      맨 위 항목에 점을 찍고, 아래로 내려가며 “이걸 더 하고 싶은가”를 묻습니다. 그렇다면 점을 찍고 그 항목이 새 기준이 됩니다. 끝까지 가면 마지막에 점 찍은 것부터 합니다. 하나를 끝내면 방금 한 자리 이후만 다시 훑습니다. 다 못 해도 됩니다. 조금이라도 했으면 끝에 다시 적습니다.
